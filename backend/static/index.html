Telegram Chat ID

Your unique Telegram chat ID. Find it by messaging @userinfobot on Telegram.

How to get your Chat ID (5 steps)

1. Open Telegram and search for @userinfobot
2. Send any message to the bot (e.g., "/start")
3. The bot will reply with your Chat ID - it's a number like 123456789
4. Paste that number into the "Telegram Chat ID" field above
5. Enable notifications and click "Send Test Notification" to verify it works
